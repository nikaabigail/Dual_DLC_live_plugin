# Изменения

## 0.2.0-rc2 — 2026-09-28

Первый опубликованный релиз с двумя дополнительными ориентирами `hl_knee_l/r`.

- Добавлен профиль `single-knees-strict` для 17-точечной модели DLC-Live. Модель выбирается явно через `DLC_LIVE_KNEE_MODEL_PATH`; прежние профили и шеститочечный DDLP/v1 сохранены.
- DDLP/v1 расширен до 8 точек (300 байт); C++ принимает оба размера пакета. Для новых точек применяются штатные фильтры. Колени не заменяют прежний угол hip–ankle–toes и не участвуют в выборе ROI или быстрых триггерах.
- Исправлена устаревшая история медианного фильтра: возраст измеряется в исходных `frame_id`, история очищается при повторном обнаружении и перезапуске счётчика. Исправление относится ко всем точкам. После пропусков результаты намеренно могут отличаться от прежней версии.
- Для новой модели добавлен проверяемый constant-zero padding после штатного crop/resize. Прежние профили не включают эту предобработку.
- Добавлен воспроизводимый просмотр видео через тот же DLC-Live/ROI и нативный C++ replay. Визуал показывает окончательно выбранную сторону.
- Опубликованы Windows x64 Release DLL (Open Ephys API 10) и экспорт `snapshot-best-050` как отдельные release assets.
- В `experiments/knee_slow_loop` сохранены отдельные численные и очередные прототипы с переносимыми синтетическими тестами. Они не подключены к рабочему контуру.

Статус: **предварительный релиз**. Проверена программная совместимость и повторное воспроизведение; полная аппаратная задержка и live-интеграция медленной аналитики не подтверждены. Улучшение согласия колена с разметкой относится к отдельной экспериментальной обработке. [Подробная проверка](docs/VALIDATION_2026_09_28.md).
